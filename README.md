# Student Placement Prediction

## Overview
This is a beginner Machine Learning project that predicts whether a student will be placed based on two features:
- CGPA
- IQ

The model is built using Logistic Regression in Python with Scikit-learn.

## Files
- Placement_Prediction.ipynb - Google Colab notebook
- placement.csv - Dataset

## Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
